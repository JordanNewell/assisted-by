assisted-by

the AI-assisted contributor class · a git commit-msg hook

Git gives credit in three classes: author, human co-author (Co-authored-by:), and bot ([bot] accounts). AI coding agents fit none of them — so every AI-assisted commit in the world either masquerades as a human co-author or is stripped to nothing.

assisted-by implements the fourth class: a vendor-neutral, opt-in trailer that rewrites vendor ads into honest disclosure.

Before:  Co-Authored-By: Claude <noreply@anthropic.com>
         🤖 Generated with Claude Code

After:   Assisted-by: my-agent

Grammar

Assisted-by: <agent-name> [; tool=<tool>] [; model=<model>]
           [; mode=generated|edited|reviewed] [; id=<operator-local-id>]

Everything optional. Default absent — nothing stamps itself. The class never gates. Assisted-by: the robots is fully conformant.
